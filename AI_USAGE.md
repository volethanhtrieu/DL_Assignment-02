## Rules we followed

- No result, number or example was taken from the AI. If a value was not in our run output, it was not written.
- Every AI-drafted cell was read, run on Colab and explained by the member before it was kept.
- Every module was tested with check cells in the notebook before its results were used: label names, the 7 split checks after filtering (no overlap, ≥ 5,000 train rows, 6 classes per split), one forward pass with starting loss ≈ ln 6, trainable-parameter counts full vs frozen, identical BERT and DistilBERT token ids, reloaded checkpoint = best epoch in the history, and 0 missing files in the final export. All checks passed.
- Model selection rules were fixed on validation before any test result; the test set was evaluated once.
- No credentials were shared with the AI. The W&B key is read from Colab Secrets and never written in the notebook.
